# Psychiatric Hospital Management System

Учебное настольное приложение для управления пациентами, палатами, медицинскими записями, назначениями и отчётностью психиатрической больницы. Проект ранее использовался на учебной и производственной практиках.

## Технологии

- C#, WPF, .NET Framework 4.7.2
- Microsoft SQL Server (SQL Server Express), `System.Data.SqlClient` (SQL-запросы без Entity Framework)
- XAML, MaterialDesignThemes
- Генерация PDF-отчётов: внешний Python с библиотекой ReportLab

## Возможности

- Авторизация пользователей (роли `admin`, `doctor`, `nurse`)
- Регистрация, поиск, просмотр и выписка пациентов
- Медицинские карты и записи врачей
- Создание, выполнение, отмена и завершение назначений
- Управление палатами и переводами пациентов
- Отчёты по пациентам, палатам, диагнозам, экспорт в PDF
- Запись ряда действий в `AuditLog`

## Восстановление и запуск локально

> Важно: исходная база данных и реальные записи **не сохранились**. SQL-файлы ниже реконструированы по отчёту о проекте и текущему исходному коду. Это новая тестовая база, а не восстановление прежних данных. Работоспособность сценариев на живом SQL Server пока не проверена.

1. На Windows установить **Visual Studio** с поддержкой разработки на .NET Framework и **SQL Server Express** (плюс SQL Server Management Studio для работы с БД).
2. Подключиться через SSMS к серверу `localhost\SQLEXPRESS` с **Windows Authentication**. Сам SQL Server Express должен быть запущен.
3. В SSMS открыть и выполнить `sql/01_create_database.sql`. Он создаст `PsychiatricHospitalDB` и восемь таблиц, **не удаляя существующие данные**.
4. Открыть и выполнить `sql/02_demo_data.sql` — добавятся 3 тестовых пользователя и 3 палаты. При повторном запуске существующие демо-записи не дублируются.
5. Открыть файл `PsychiatricHospitalWPF.sln` в Visual Studio. Восстановить NuGet-пакеты из `packages.config` и собрать приложение.
6. Проверить строку подключения в `Utils/DatabaseConnection.cs`:

   ```csharp
   @"Data Source=localhost\SQLExpress;
     Initial Catalog=PsychiatricHospitalDB;
     Integrated Security=True;";
   ```

   Если экземпляр SQL Server называется иначе, изменить **Data Source** на локальное имя своего экземпляра. Windows-пользователь, запускающий приложение, должен иметь права доступа к этой базе.
7. Запустить проект в Visual Studio. Для тестовой базы учётные данные:

   | Логин | Роль | Пароль |
   |---|---|---|
   | `demo_admin` | Администратор | `Demo2026!` |
   | `demo_doctor` | Врач | `Demo2026!` |
   | `demo_nurse` | Медсестра | `Demo2026!` |

   **Демонстрационные пароли не подходят для реальной эксплуатации.** В текущем проекте пароли проверяются через несолёный SHA-256; для рабочей системы алгоритм хранения паролей необходимо заменить.
8. Для PDF-отчётов дополнительно установить Python и ReportLab:

   ```powershell
   python -m pip install reportlab
   ```

   Команда `python` должна быть доступна в `PATH`. Экспорт PDF вызывается через внешний Python-процесс; это отдельная зависимость приложения.

## Ограничения и статус

Это архивный **учебный**, а не предназначенный для эксплуатации в медучреждении проект. База и тестовые данные восстановлены по документации, но сборка, авторизация и сценарии CRUD ещё требуют проверки в локальной среде с SQL Server. Не вводите реальные персональные и медицинские данные в демонстрационную базу.
